## Sistema recuperado

Bifurcación: tronco hueso, rama gris para lo real y rama rosa para lo hipotético. Negro `#0D0D0F`, hueso `#EFE9DF`, gris `#5F5E64`, rosa `#E4007C`. Un acento rosa por pieza. Instrument Serif para títulos/remates, Instrument Sans para textos/subtítulos, Geist Mono para fechas/datos. La guía histórica declara aprobación del 25/oct/2026; se atribuye al documento.

Se conserva el kit intacto. El Dr. V7 usa negro/hueso/gris y se propone junto a este sistema; su aprobación visual sigue pendiente. Los kits anteriores y el ZIP rosa/amarillo se conservan como antecedentes dentro del historial del personaje, no sustituyen v3.
