# Skills del canal · Aquí el hubiera sí existe

Copia de las skills usadas para producir el ep04 «¿Y si Cristiano Ronaldo hubiera nacido en México?» (29 oct 2026). Las originales viven en `Ai Lab School OS\.agents\skills\` y en la cuenta de Claude; esta copia es la referencia del canal.

| Skill | Para qué | Paso del flujo |
|---|---|---|
| [`kit-video-ai-lab`](kit-video-ai-lab/SKILL.md) | Elegir y cargar las skills de video según la línea | Antes de empezar |
| [`escritura-guiones-ai-lab`](escritura-guiones-ai-lab/SKILL.md) | Gancho, juego, escalada, remate y autocrítica del guion | Guion |
| [`voz-elevenlabs`](voz-elevenlabs/SKILL.md) | Candado y manifiesto: una sola toma, sin gastar créditos dos veces | Voz |

| [`stickman-animation-direccion`](stickman-animation-direccion/SKILL.md) | Tomas con el kit (poses, IK, cámara, luz, sellos, etiquetas, transiciones) y trampas del motor | Tomas |
